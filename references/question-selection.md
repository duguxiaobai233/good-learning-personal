# 选题与用途分配

本细则用于生成课程前的选题与例题、独立练习、复习分配。原题转录与疑点处理沿用 [每日学习](daily-study.md)，外部检索按 [资料检索](source-search.md)。先选后编，不把现成题的存在当作已经匹配，也不为满足“迁移”形式优先制造新题。

## 识别材料和题目

依据用户说明及正文识别教材（书名、作者、版次）、原课程课件／教师讲义（课程、教师、单元）、作业／习题单、试卷／真题、答案解析、已生成讲义。记录实际取得范围；同一文件可包含多类内容。用途不明确时保留待确认，不靠扩展名推断。

对题目另记原材料用途：讲解例题、课堂练习、课后作业、章后题、考试题或未注明。来源身份与本次教学用途分开。材料附有答案不等于用户已看答案；已生成讲义用于判断教过什么、展示过哪些解法，不作为新的独立原始来源。

## 根据目标筛选，按来源优先

先用知识清单编号确定本讲要检验的具体能力。例如“根据有效面积和两侧压强求净推力”，比“压力”更能判断题目是否适用。复习题可对应已学目标，标明其复习用途；不要求每题都只考当天新知识。

候选题需满足：实际考查目标匹配；所需前置已经讲授、确认掌握或题目完整提供；深度、计算量和预计用时合适；必要题干、共同材料、图表可取得；能独立求解核对。检查与已选题的重复及新增训练价值。未学的前置不能因同章或同课程就视为已具备，题目超出阶段时延期或换题，不暗改原题或擅自扩大当天范围。

在适配前提下执行：

1. 用户明确指定要完成的题优先处理。超出阶段时说明所需前置，安排补学或延期；不静默跳过指定题。
2. 优先选用户提供的教材、原课件、作业及习题资料中的适用原题。教师明确布置的题优先保留为练习；同层来源按本讲匹配程度、用途和完成要求选择，不规定课件永远高于教材。
3. 本地题不足或无法判断典型题型时，检索公开高校课程和开放教材中的适用题。来源可用性与引用方式按资料检索细则核对。
4. 仍有明确缺口再新编或明确改写，沿用每日学习中的编题和求解验收要求。

新编或改写题在内部记录具体理由，如某目标缺练习、现成题都已展示解法、现有题难度不适合。不能只写“增加迁移”而不说明需要检验什么。无需穷尽整本书或互联网，但不能未检查已提供的相关章节就认定无题。仅未检查、无法读取与确实无适用题应分别记录。

## 例题与独立练习共同安排

先确认每个主要训练目标是否有未展示完整解法的适用题可用于独立检验，再确定演示方法所需的代表例题，避免把全部原题提前解完。不设固定题量或比例；尊重用户要求的范围与实际学习时间。

- 明确的讲解例题优先用于示范；明确的作业、课堂练习和章后题优先作为独立练习。
- 用途未注明的题，根据是否需要演示该方法、是否还保留适用练习来分配。材料附有解析但尚未展示给学习者的题，仍可作为候选练习；不要把“有答案”误判为“已学过”。
- 独立练习只在前部提供完整题干及原有提示，完整答案后置；原题自带的提示与分问照原样保留。不得把答案误混进题干。例题完整解析与题目相邻。
- 用户明确要求逐题讲解全部题时，先满足该要求，再另找或新编独立检验题，不为保留练习擅自扣下解答。
- 只有一道适用原题时：知识讲解足以支持独立作答，就留作练习；确需示范，就作例题，再按来源顺序补练习。未找到其他题可安排后续复做，但不能把复做宣称为新的独立迁移证据。
- 已在生成讲义或答疑中展示完整解法的题，记录为“解法已展示”，再次使用属于复习；这不代表用户已阅读或掌握。实际看过解法的用户反馈也应记录。
- 教材、课件间的同一道题合并识别并保留各出处；仅换数字的近似题注明关系，不冒充全新的实质迁移。

## 简明题目索引与接续

在科目已有的 `源文件/题目索引.md` 中按当前范围逐步记录：

| 字段 | 内容 |
|---|---|
| 稳定题目编号、来源定位 | 文件／书名及版次、页码、原题号；外部题补课程与链接，多处来源合并。 |
| 知识与前置 | 对应知识点编号、实际考查任务、必要前置和适配判断。 |
| 原材料用途与本次用途 | 分别记录原例题／作业等身份及本次例题／练习／复习／暂缓用途，附课程位置。 |
| 展示与作答状态 | 解法是否已展示、用户是否反馈看过、是否提交作答及待验证／复做状态，未知保持未知。 |
| 选择或补题理由 | 简短记录训练缺口、暂缓原因或改写关系；不写进题前泄露方法。 |

题干保存在原材料与课程源稿，索引以定位为主。写课程只更新已安排、已展示状态；真实作答与掌握依据用户证据更新，不把例题读过等同会做。每次接续先查相关范围，避免重复选用和跨版本题号混淆。

## 交付检查

对照材料与本讲目标检查：已有适用原题是否被忽略；每题是否有明确知识目标和已具备前置；例题是否讲清方法且保留独立检验机会；已讲题与重复题是否被误标为新题；新编题是否填补具体缺口。基础巩固、方法选择与迁移按阶段安排，保留有价值的常规题，避免为了新颖牺牲适配性。

继续执行每日学习中的原题保真、逐题求解、完整解析与答案后置验收。索引用于选题判断，不替代核对实际题目，也不替代真实作答证据。
