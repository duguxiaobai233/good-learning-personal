# 选题与用途分配

只使用用户提供或明确指定且实际可读取的课件、教材、练习册、作业和试卷原题。原题转录与完整解析按 [每日学习](daily-study.md) 执行；不新编、不改写，不检索公开高校课程或开放教材补题。

## 识别材料与题目

依据用户说明和正文识别书名、作者、版次、课程、教师、单元与实际取得范围；同一文件可包含多类材料，不靠扩展名推断。题目记录原用途，如例题、课堂练习、作业、章后题或考试题，与本次用途分开。

材料附有答案不等于用户已看答案。已生成讲义用于判断教过什么与展示过哪些解法，不作为新的独立原始来源。教材与课件中的同题合并识别并保留各出处。

## 知识匹配与混合来源

先用知识清单编号明确训练目标，按实际考查的知识与能力匹配题目，再结合来源、难度、前置和用时安排；不固定课件、教材、练习册的优先顺序。用户明确指定的题优先处理，不静默跳过。

在相应材料可读取且存在匹配原题时，一讲或一个知识单元应同时包含课件题和课本或练习册题，不要求每个小节凑齐来源，不设固定比例。课件题联系课程要求，课本与练习册补充不同问法、分析角度与难度；具体用途由题目内容决定，不预设来源对应难度。

检查题干、共同材料、图表和代码是否完整可取得，能否实际求解核对。未检查、无法读取与确实没有匹配题分别记录。缺题时先完成已有材料支持的内容，说明具体缺口，不外搜补题、不自行补造。

## 主动选择挑战题

主动选取复杂推理、多关系整合、不熟悉的表示方式和深入条件判断的原题，帮助突破舒适区；不因题目较难或尚未熟练而默认排除。不固定难题比例，也不要求完成全部简单题后才能挑战。

少量必要前置欠缺时先补讲再挑战；跨度较大时说明缺口与补学路径，结合目标安排。不能因同章就假定前置已具备，也不能为适应水平改动原题。基础巩固仍可保留，题量依目标与可用时间调整。

## 例题与练习共同安排

根据示范需要和独立检验机会分配原题，不设每例固定题量。原例题优先示范，作业与章后题优先作练习，具体安排服从知识匹配和用户要求。

- 用户要求逐题讲解全部题时完整满足；其他独立检验只能从允许材料中另选原题，缺题如实说明。
- 只有一道适用题时按教学需要用作例题或练习，不因此新编、改写或安排错题复做。
- 练习按“完整原题—简明答案—详细解析—题型与模型总结”呈现，答案与原题明确分开，方便立即核对，不要求提交后才能查看。
- 已展示完整解法的题如再次被选用，标明展示历史，不当成新的独立掌握证据。实际是否看过或掌握仍依据用户反馈。

## 简明题目索引与接续

在科目 `源文件/题目索引.md` 按当前范围逐步记录：

| 字段 | 内容 |
|---|---|
| 稳定编号与来源 | 文件／书名、版次、页码、原题号；用户指定的外部材料保留链接，多处来源合并。 |
| 知识与前置 | 知识点编号、实际考查任务、必要前置、缺口及补讲安排。 |
| 原用途与本次用途 | 原例题／作业身份，本次例题／练习／挑战／暂缓用途及课程位置。 |
| 展示与作答状态 | 答案或解法是否已展示、是否反馈看过、实际作答与掌握证据；未知保持未知。 |
| 选题理由 | 知识匹配、来源组合、挑战价值、暂缓原因或未解决的材料缺口。 |

索引以定位为主，题干保留在原材料与课程源稿。生成课程只更新安排与展示状态，不把答案已展示等同于用户已掌握；不设置错题复做日期或重复验证任务。

## 交付检查

核对每题真实出处、知识匹配、混合来源和挑战安排；必要前置是否补讲或说明路径；有没有暗改题目、外搜补题或忽略合适难题；是否完整展示答案并区分展示与掌握。随后执行每日学习中的原题对照、逐题求解、完整逻辑和模型总结验收。
