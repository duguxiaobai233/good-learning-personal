# 每日学习与调整

## 开始一日课程

本机教学偏好更新于 2026-10-31，保留 2026-10-26 对讲解与练习的要求，并依据用户对正面建立概念、首次解释术语和符号的反馈完善内容生成。本节细化原有的自成体系要求，并替代“每例后必配同构填步题”的固定流程。

以当天计划、剩余时间、前次错题和新要求确定学习量。开头给出今日目标和预计用时。时间不足时缩小本讲范围、减少练习数量，保证所选范围讲透；不能为了覆盖更多页数或凑题量，把必要知识留给用户自行翻课件。学习单元按概念和前置关系衔接，不机械地用“一道例题加几道换数题”代替课程。

## 生成内容应足以独立学习

默认用户尽量不再阅读原课件。写作前先确认本讲对应的原材料内容和必要前置，再用连贯的教材式说明重建知识：相关术语是什么、对象或部件起什么作用、机制怎样发生、量与符号表示什么、公式为何可用、限制条件和易混概念是什么。具体详略适配学科、已有水平和本讲目标，不必机械填满相同栏目。

原材料中的图、表、代码、状态变化和被简写的步骤，凡理解本讲或完成练习所必需，均应在生成内容中重绘、转述或展开说明。涉及程序与硬件时，要讲清相关状态、控制条件和执行先后；涉及公式时，要解释符号、单位、关系来源和适用范围。首次出现的必需概念在此处说明，不能用页码、缩写、术语堆叠或“课件已讲”代替。不能只把例题算式拆成若干步、每步加一句理由，就视为已经讲清原课件知识体系。

完整例题放在相关知识讲解之后，用来展示如何识别问题、选用知识、推理、计算和检验结果，包含必要理由和边界检查；例题允许充分解释。原材料未取得或图文无法辨认时，明确未核对的范围；可据已确认材料和可靠来源解释，但不能把补充讲解冒充原课件原文，不能臆造页码。

### 概念、符号与理解顺序

正文以正面建立认识为主。新概念先说明它是什么、描述什么对象以及在当前问题中的作用；新方法先说明如何使用及其理由。易混辨析和反例放在相应概念已经建立之后，用于解决具体混淆。必要的适用条件随知识一起说明；减少无助于当前理解的否定和告诫，不机械禁用否定句，也不设置句式比例。

写作前根据已确认的学习水平梳理本讲的前置关系，区分核心知识、必要前置和后续拓展。需要的前置在使用前补齐，新内容接续已解释的知识，并说明为何此时引入。一个段落集中推进一个主要关系，避免连续引入多个未解释概念。当前不用的高级术语、特殊应用和例外延后；若本讲确实需要，就提供足够解释。按内容选择组织方式，不给每个知识点机械套用固定栏目。

首次出现的概念和符号在使用处解释，解释应能让读者指认其对象和含义：

- 术语先用当前水平能懂的话说明，再给出名称；定义中用到的其他术语也应已有解释。
- 物理量说明描述哪个对象的什么性质或作用；字母与下标说明各自所指，必要时给出单位。抽象数学或其他学科符号说明对应对象、角色或操作，不强加物理含义。
- 涉及方向、位置、时刻、正负号或参考零点时，说明当前采用的约定。图、公式与正文采用一致的符号。
- 微分、积分、求和等记号也属于需要解释的内容。根据已知数学基础补足当前所需的操作含义；涉及局部量时，说明为何分成小块及局部近似与极限的关系，避免只把带有新记号的公式读一遍。
- 同一连续讲解中，已经解释且含义不变的内容无需重复定义；跨节间隔较长时可简短提醒。符号的含义、所指对象、适用条件或参考基准改变时，就地明确说明。符号表可用于回查，不能代替首次解释。

核心关系需要把具体对象、语言含义和公式联系起来，并给出适合当前水平的理由。按知识需要选择直观情境、简短数值例子、图或推导，不要求每个概念都有全部形式。涉及公式时，先让读者知道各量描述什么，再解释数量关系为何成立、何时成立；区分定义、定律、推导结果与近似。单位核对用于检验，不能单独充当关系的推导。

例如，初学压强时，可先讲均匀压强下单位面积受力与总受力的关系，再进入小面元受力；讲曲面受力时，说明各处推力的方向及矢量合成方式，使读者知道如何求合力。该例用于说明讲解深度，不要求其他学科照搬流体力学的步骤。完整例题仍放在相关知识之后，概念内的短示例用于建立含义。

## 结构与过程需要实际配图

讲解、例题或练习涉及连接关系、信号传递、空间组织、状态变化或曲线规律，并且图对理解或解题有实质作用时，按 [教学配图](technical-diagrams.md) 主动生成实际图。自动控制的框图/信号流图、栈和队列的逐步状态等不能只转述为文字或指回原课件。说明图中符号和阅读顺序，核对图与方程/操作一致；必要条件图随题给出，答案路径图放在解析中。两个 PDF 版本保留同样的图，独立题的作答空白放在完整题干和附图之后。正文应引导读者从图中找到当前讨论的对象、方向或状态，并说明它们与公式的对应关系；按图是否帮助建立具体认识验收，不能只核对是否配了图。

## 题干完整，方法由学习者选择

每道独立题目应给全解题所需的任务事实：情境与目标、数据和单位、初始状态、约束、精度或边界条件，以及用到的程序、图表和观察结果。不能以“仍按上例”“其余同前题”“见 S3 某页”代替条件；来源是溯源信息，不是读题入口。多题共享材料时，在本组前完整给出并明确适用范围，不能藏在已解例题里。

完整题干不等于把知识点、公式和求解路线写进题干。需要运用的知识应在本讲前文教清，读者运用所学独立解题；不能因减少提示而制造条件不足或调用尚未教过的知识。题目给定模式、工具或状态若确属任务约束就应保留；若目标是考查自主选择，不能预先替用户选好方法。

独立题默认不预给本应由学习者自行选用或推导的关键公式、应补的具体语句、关键中间结果或只剩代数运算的推理链；公式或程序若本来是分析对象或必要给定条件，应提供。标题、题型标签和题前提醒也不能泄露待判断的方法或错误位置。可以有多个任务问句，但不要用连续小问替用户完成关键建模和路线选择。可在课程单元层面说明学习目标，不在每道题旁揭示该题考查的具体解法。

来源说明放在题末或统一的来源区，简洁区分“用户原题”“由用户原题改写”和“新编题”；新编题的知识依据不能冒充原题出处，未读取原材料时不能编造 S3 页码。题干优先呈现自然可读的任务，不以“同构填步题、新编、依据某页”等长标签开头。

## 练习的层次与实质变化

以少量、无路线提示的独立练习检验本讲目标，再按需要安排迁移与混合回顾。零基础通过缩小知识跨度、减少耦合条件、使用较短情境来降低负担，仍保留需要独立判断的步骤；不通过泄露整条思路来代替合理降难度。无需让每道题都成为难题，也不固定每个例题对应相同题量或题型。

同构填步或局部提示仅在用户明确要求，或实际反馈表明卡在某个具体步骤时作为临时支架；不得默认每个例题后都安排，也不得将其当作独立掌握的主要证据。默认题目和答案分开；需要提示时根据真实卡点逐步给出，不在题前预设完整提示链。

练习组应包含需要自行选择方法或对关键条件作实质判断的任务。可依据本讲知识选择：从结果或现象反推原因、诊断与修复错误方案、比较并论证不同方案、在约束下设计并验证、处理条件改变或方法失效、整合已学知识。基础概念课也可用辨析、分类、预测和反例来检验理解，不强行跨章拔高。

只换数字、变量名或情境名称而沿用完整例题同一路线，只能算基础重复，不能标成实质迁移或充当练习组主体。编题时应明确新增了哪项决策或关系，确认所需知识已经讲过；变化的教学说明和关键判断放在答案解析或内部设计记录中，不提前揭示给做题者。

这种安排参考原有的研究线索：[Chi 等（1989）](https://education.asu.edu/lcl/publications/chi-m-t-h-bassok-m-lewis-m-reimann-p-glaser-r-1989-self-explanations-how-0)关于例题自我解释的观察、[Renkl 等（2002）](https://doi.org/10.1080/00220970209599510)关于逐步减少例题提示的实验，以及[Rohrer 与 Taylor（2007）](https://doi.org/10.1007/s11251-007-9015-8)关于间隔、穿插数学练习的实验。将这些线索用于本技能属于教学设计推断，不意味着所有学科、每个例题都要套用填步题或固定题量；本次改动依据用户明确反馈调整。

## 答案、排版与交付前核对

所有独立练习在前，完整答案与解析集中放在后部，解释方法选择、关键条件、推理与结果检查，不能只报数值。图表与程序必须随题可读；若新表达超出转换脚本能力，调整文稿结构或直接写 TeX，不能删除必要材料。核心例题原则上单独起页，但知识说明应按逻辑连贯组织，不把每个短概念强行另起页。

发布前先独立检查讲解正文，再逐题核对练习。以当前学习者已确认的基础为起点，沿正文顺序检查以下项目；发现缺口就修订相关段落，不用增加一条“注意”代替解释：

- 读者能否说出每个核心概念是什么、描述什么对象、有什么作用？是否尚未建立概念就堆积例外、禁令或易错提醒？
- 新术语、字母、下标及数学记号能否在首次使用处找到足够解释？解释是否指明含义和对象，而非仅重复名称？是否存在用另一个未解释术语解释当前术语的情况？
- 每次知识推进是否具备必要前置？一个句段是否跨过多个未解释概念？当前不用的拓展是否干扰了主线？
- 核心公式和结论是否给出了当前水平可理解的依据，并连接到具体对象或明确的数学对象？是否把单位正确误当成关系已被证明？
- 符号含义、所指对象、方向约定和参考基准是否一致，改变时是否说明？定义、定律、近似与推导是否区分，单位、量纲及适用条件是否准确？
- 涉及空间、方向或状态时，读者能否结合图和正文指出对应关系？图中符号和箭头是否与公式一致？

随后实际逐题解答并做以下检查；有失败项就先修订讲解或题目：

- 仅阅读生成课程，是否已学到完成本讲练习所需的概念、关系、符号和方法？缺口应补进讲解，不能临时在题干泄露解法。
- 隐去原课件及已解例题，每道题的事实条件、图表或程序是否仍齐全？题目是否因遗漏条件而无法确定答案，或应明确接受多个合理答案？
- 标题、标签、已知条件和分问是否替用户完成了本来要考查的判断、计算中间结果或方法选择？删除泄题内容，同时保留真正必要的任务事实。
- 练习组是否除了换数字就没有新的判断或结构变化？题目是否调用尚未讲过、也没有明确提供的知识？难度是否符合当前学习水平？
- 对照题干完成答案，检查数据、单位、条件、代码、边界与预期结论是否一致，避免靠猜作者意图解题。

把每一天完整课程整理成同源的“紧凑排版型”和“宽松排版型”两份 PDF。按学习日建立 `每日学习/D001-YYYY-MM-DD`，顶层只放该日最终 PDF，课程文本、TeX、配置和学习记录放在其 `源文件` 子目录；未开始的日期不建空文件夹。紧凑版只减少作答空白，不能压缩知识讲解或挤放完整例题；宽松版按独立题实际需要留作答区，已解例题不留空白。两版题干、必要材料、讲解和答案完整一致，均能独立使用；不能把一份 PDF 的必要条件放到另一份里。

两个版本均标明今日目标、预计用时、必要前置、完整知识讲解、例题、独立练习、后置答案、完成标准和反馈方式。必学内容全部在生成课程内，外部课件和资料仅用于核对或选读。课程内导图按需放入两份 PDF，不另导出。**所有 PDF 均由 XeLaTeX 或 LuaLaTeX 实际编译。**交付前逐页检查中文、公式、程序、图表、断页、留白和题干完整性。

## 答疑与错题

答疑先定位用户卡住的步骤，给出必要解释、演示或反例，并用一两句话归纳可复习的结论。对尚未完成的练习，不主动泄露全部答案，除非用户要求。

用户报错题或提交作答后，记录：题目或出处、考点、用户答案与正确思路、错误原因（仅在有证据时填写）、下次复习时间或触发条件。每道错题写明具体错步、正确的第一步和完整订正，再给一道改变条件的复做题，答案集中放在后部。可把错误归为概念、方法、计算、审题、记忆或时间管理，但以用户实际表现为准。对高频错误安排相近题再次验证；已掌握的内容减少重复，未掌握的前置知识提前补齐。用户要求演示时明确标注“模拟作答／模拟错因”，不把演示写成真实答题表现。

收到用户的作答、错题、实际用时或完成情况后，及时更新对应日期文件夹中的学习记录：已完成的题、待补内容、可证实的错因、掌握状态与下一步。当前课程若因反馈增删讲解或练习，同步更新文本并重新编译两个 PDF 版本；若只影响后续安排，保留已发课程，调整下一日内容和必要的备考计划。结束时简要汇总：今天完成什么、哪些仍不稳、下次该做什么、计划作了哪些调整及其依据。跨天保留进度，不因一次失误大幅重排整个计划；未收到反馈时保持待验证。

## 长周期导图

备考期超过一个月且今日内容有多个相互关联的概念时，制作以概念关系为主的导图，突出前置关系、适用条件和常见混淆点。用户在完成课程后另要总结思维导图时，制作独立的 SVG，可附 PNG 方便直接查看；这种总结图无需 LaTeX，并须把知识点与实际错题或显著标明的模拟错题逐一联系。课程正文 PDF 中的概念导图仍按上文规则放在 PDF 内。导图只概括实际学过的内容，避免把未学章节或未提交作答伪装成学习成果。
