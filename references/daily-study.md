# 每日学习与调整

## 开始一日课程

本机教学偏好更新于 2026-11-16：只选已有原题，知识匹配优先，主动安排挑战，完整解答整题并讲解模型的一般性；答案就地优先展示，不附加易错提醒，不设错题复做。

以当天计划、剩余时间、前次错题和新要求确定学习量。开头给出今日目标和预计用时。

## 先选题并分配用途

每次生成课程前读取 [选题与用途分配](question-selection.md)，按知识目标检查允许材料中的原题，共同安排例题、练习与挑战。在材料具备时混合课件与课本或练习册来源。用户要求全部讲解时完整满足；材料不足说明缺口，不新编、改写或检索公开高校与开放教材补题。

## 讲义讲解

遵循 [主说明中的七条讲义讲解原则](../SKILL.md#讲义讲解原则)。只有习题时，按原题组织课程并分配例题与练习；用户要求逐题讲解时覆盖指定题目。

讲义先完整呈现知识讲解与例题，例题紧随对应知识点，不在讲解过程中穿插独立练习。例题之外的所有题目，包括基础练习与挑战题，统一集中放在正文讲解结束后的“课后练习”部分，按知识点及学习顺序排列。每题仍按“完整原题—简明答案—详细解析—题型与模型总结”呈现。

## 原题练习与挑战

原题保留全部条件、提示、公式和分问，必要共同材料在本组前完整提供并注明适用范围，不能用“仍按上例”或页码代替实际题干。来源短注与原题正文分开，保留可核对的文件、版次、页码与题号。

按选题细则混合课件题与课本、练习册题，主动选取有挑战性的原题；可考方法选择、反推、方案比较、条件判断和知识整合，具体任务必须来自实际原题。少量前置先补讲，较大缺口说明路径，不因当前不会就排除难题，也不暗改原题降难度。

不生成同构填步题或变式题。答疑可以针对真实卡点解释，但不把原题改造成新题。题量和基础／挑战分配依据目标、时间与反馈，不设固定比例。

## 答案、排版与交付前核对

每道习题按“完整原题—简明答案—详细解析—题型与模型总结”呈现，简明答案紧接原题，便于优先核对；证明、论述和设计题先给核心结论或答案要点。不强制隐藏答案或要求提交作答后才展示。图表与程序必须随题可读；若新表达超出转换脚本能力，调整文稿结构或直接写 TeX，不能删除必要材料。核心例题原则上单独起页，但知识说明应按逻辑连贯组织，不把每个短概念强行另起页。

交付前将所有引用题目逐一与原材料对照，覆盖例题和独立练习：

- 题干是否完整转录，情境、条件、数据、符号、图表和全部分问是否保留？是否被概述、“已知—求解”列表或新编题替代？
- 原有提示、公式和分问是否被出题优化规则误删？排版整理是否意外改变了含义？
- 新增解释、订正与假设是否在原题之外明确标注？疑点说明是否与其对作答的影响相称？
- 原题各问是否都有对应解答或明确的待澄清说明？要求覆盖的题目是否均有去向，来源标签是否与实际使用方式一致？

再核对选题决策：用户材料中是否有更适用却被忽略的原题？每题是否对应本讲目标或明确安排的复习目标，必要前置是否具备、已补讲或有明确补学路径？是否把全部适用作业讲成例题，或把已讲题、重复题当成新的独立检验？是否在材料具备时混合来源并主动安排挑战？是否因尚未熟练而直接排除难题？按选题细则修正用途或换题，不暗改原题。

再实际逐题解答并做以下检查；有失败项先修订讲解、转录或选题安排，原题本身的问题与原题分开说明：

- 隐去原课件及已解例题，每道题的事实条件、图表或程序是否仍齐全？题目是否因遗漏条件而无法确定答案，或应明确接受多个合理答案？
- 原题提示、公式和结构是否完整保留？题目与答案是否清楚分开，原题后是否立即展示简明答案与完整解析？
- 混合来源和挑战是否落实？必要前置是否补讲或说明路径，而非暗改题目或因当前不会就一律排除？
- 对照题干完成答案，检查数据、单位、条件、代码、边界与预期结论是否一致，避免靠猜作者意图解题。

把每一天完整课程整理成同源的“紧凑排版型”和“宽松排版型”两份 PDF。按学习日建立 `每日学习/D001-YYYY-MM-DD`，顶层只放该日最终 PDF，课程文本、TeX、配置和学习记录放在其 `源文件` 子目录；未开始的日期不建空文件夹。紧凑版减少作答空白并保留舒适的正文行距与例题分页；宽松版按独立题实际需要留作答区，已解例题不留空白。两版题干、必要材料、讲解和答案完整一致，均能独立使用；不能把一份 PDF 的必要条件放到另一份里。

两个版本均标明今日目标、预计用时、必要前置、完整知识讲解、例题、独立练习、就地展示的答案、完成标准和反馈方式。课程内导图按需放入两份 PDF，不另导出。**所有 PDF 均由 XeLaTeX 或 LuaLaTeX 实际编译。**交付前逐页检查中文、公式、程序、图表、断页、留白和题干完整性。

## 答疑与错题

答疑先定位用户卡住的步骤，给出必要解释、演示或反例，并用一两句话归纳可复习的结论。习题答案优先展示以便核对，不以尚未提交作答为由隐藏答案；答疑围绕具体卡点展开。

用户报错题或提交作答后，记录题目出处、考点、作答原貌、具体错步、有证据的错因、完整订正和掌握状态。可按实际表现归为概念、方法、计算、审题、记忆或时间管理问题，未知原因保持未知或针对作答追问。取消自动复做题、复做日期、勾选表与重复验证任务；保留真实记录，通过反馈调整后续讲解和原题选择。用户要求演示时显著标注“模拟作答／模拟错因”，不计入真实表现。

收到用户的作答、错题、实际用时或完成情况后，及时更新对应日期文件夹中的学习记录：已完成的题、待补内容、可证实的错因、掌握状态与下一步。当前课程若因反馈增删讲解或练习，同步更新文本并重新编译两个 PDF 版本；若只影响后续安排，保留已发课程，调整下一日内容和必要的备考计划。结束时简要汇总：今天完成什么、哪些仍不稳、下次该做什么、计划作了哪些调整及其依据。跨天保留进度，不因一次失误大幅重排整个计划；未收到反馈时保持待验证。

## 长周期导图

备考期超过一个月且今日内容有多个相互关联的概念时，制作以概念关系为主的导图，突出前置关系、适用条件和常见混淆点。用户在完成课程后另要总结思维导图时，制作独立的 SVG，可附 PNG 方便直接查看；这种总结图无需 LaTeX，并须把知识点与实际错题或显著标明的模拟错题逐一联系。课程正文 PDF 中的概念导图仍按上文规则放在 PDF 内。导图只概括实际学过的内容，避免把未学章节或未提交作答伪装成学习成果。
